## About

Undergraduate researcher at the University of North Carolina at Pembroke focusing on **reinforcement learning to improve reasoning in large language models**. My research centers on developing better reward design for LLM reasoning through step-level intrinsic calibration.

Currently working on **SLIC (Step-Level Intrinsic Calibration)**, which combines process supervision with confidence measurement to train models that are both accurate and well-calibrated about their uncertainty.

**Research Interests**: Reinforcement Learning • LLM Reasoning • Process Supervision • Reward Design • AI Safety

## Current Research

### Primary Research: SLIC (Step-Level Intrinsic Calibration)
Developing reinforcement learning methods to improve reasoning in large language models through step-level intrinsic calibration. This work combines process supervision with confidence measurement to create models that understand their own uncertainty.

*Advisor: Dr. Shaohu Zhang (NC A&T, previously UNCP)*

## About This Portfolio

This repository contains my academic portfolio website — a modern, SEO-optimized platform showcasing my research, experience, and projects.

### Technology Stack

- **Framework**: Next.js 15.5.3 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion 12
- **Icons**: Lucide React
- **Deployment**: GitHub Pages

### Features

- Modern, responsive design optimized for academic portfolios
- Smooth section navigation with Intersection Observer API
- Keyboard navigation support (Arrow keys, Home, End)
- SEO optimized with 170+ targeted keywords
- Schema.org structured data for search engines and AI assistants
- Open Graph and Twitter Card meta tags for social sharing
- Accessibility compliant (WCAG standards)
- Fast loading performance (< 1s)

### Local Development

```bash
# Clone the repository
git clone https://github.com/najmulhasan-code/najmulhasan-code.github.io.git
cd najmulhasan-code.github.io

# Install dependencies
npm install

# Run development server
npm run dev
# Open http://localhost:3000

# Build for production
npm run build

# Run production build locally
npm start
```
